# Run the Same-Standard Check

## Purpose

Use this skill for one bounded self-reflection task. It is general wellness material, not medical advice, diagnosis, treatment, emergency support, or a substitute for qualified professional care.

## Use when

- The comparison person would be in genuinely similar circumstances.
- The question is whether the rule changes mainly because the person being judged is the user.

## Do not use when

- Roles, duties, risks, commitments, or consequences are materially different.
- The comparison would excuse a real responsibility.

## Procedure

1. Write the rule used for the user.
2. Write the rule that would be used for another person in the same role and circumstances.
3. Compare them.
4. If they differ, ask whether a real responsibility explains the difference. Keep justified differences.

## Response contract

Return: Self-rule → Same-situation rule → Difference → Justified by real responsibility? yes/no.

Keep the response concrete and proportionate. Do not infer a disorder from the user's wording. Do not remove genuine safety measures, protective boundaries, accessibility aids, medication instructions, professional requirements, or legal/compliance controls.
