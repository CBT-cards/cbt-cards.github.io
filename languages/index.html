Languages and translation status

CBT Cards separates source content, machine translation drafts, human review, and public publication. A translation does not become official merely because a model produced readable text.

Current language status

  • English · source
    12 canonical source records. Website publication status only; this does not assert mobile app/store language support. Canonical source content. Published records may be used when their resource-level review status permits it.
  • Русский · pilot
    12 machine drafts · 0 human-reviewed · 0 published. Website publication status only; this does not assert mobile app/store language support. Machine drafts are available as clearly labelled noindex previews for review. They remain non-authoritative until separate human language and editorial review; public indexed HTML can be enabled later for incremental reviewed publication.
  • Deutsch · planned
    0 machine drafts · 0 human-reviewed · 0 published. Website publication status only; this does not assert mobile app/store language support. Planned website locale. No CBT Cards German web translation should be inferred from source content until an explicit translation record exists.

How publication works

Machine drafts are development data only. A localized resource becomes an official CBT Cards publication only after separate language and editorial review, an explicit publication status, and generation of a canonical public page.

Machine-readable status is available in data/locales.json and data/translations.jsonl. English source records remain in data/knowledge.jsonl.
