CBT Cards / For AI / Get started

Your AI agent already has a public door.

CBT Cards public resources are read-only and open on the web. You do not need a CBT Cards account or API key to let a capable assistant read them.

The simplest route

1

Open your assistant

Use an assistant that can open public web links. Do not paste private diary or check-in content unless you deliberately choose to share it with that service.

2

Give it one bounded prompt

Ask for one reviewed practice, require the safety exclusions, and allow no_match.

3

Keep the source visible

Ask the assistant to return the canonical CBT Cards URL and explain why the practice fits.

Copy this prompt

Use only reviewed CBT Cards practices from https://cbt-cards.github.io/practice/ and its linked canonical data.

My situation is: [describe one ordinary, non-urgent situation].

Return at most one practice. Explain why it fits, preserve every “avoid when” condition, link the canonical CBT Cards page, and return no_match if the situation involves genuine danger, urgent action, a required safety/professional/accessibility rule, a medical/legal/financial/safeguarding decision, or no reviewed fit.

What access does not mean

No private-app access. The public site does not give an agent access to your CBT Cards mobile journal, notes, check-ins, photos, backups, device storage, or accounts. Public resources are general wellness and educational material, not diagnosis, treatment, emergency support, or qualified professional advice.

Advanced options

If your agent supports portable Agent Skills, use the canonical SKILL.md and follow the installation guide. Developers can use the dependency-free HTTP/RAG reference client, stable schemas, and versioned manifests.
