CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts and learning resources are available as canonical HTML, compact text indexes, JSON/JSONL data, and versioned agent skills. None of these resources provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • Web pages: best when an agent can browse and cite canonical pages directly.
  • llms.txt: compact discovery index for the main public resources.
  • llms-full.txt: extended source-priority, dataset, versioning, and safety guidance.
  • JSON catalog: stable IDs, resource types, canonical URLs, product scope, store links, and agent version metadata.
  • JSONL knowledge dataset: one self-contained record per public learning resource, suitable for retrieval and indexing without scraping presentation HTML.
  • SKILL.md: portable latest-version instructions for agents that support skill files.

JSONL record shape

Each record in knowledge.jsonl has a stable resource ID, locale, canonical URL, summary, key points, relation to the CBT Cards implementation, safety scope, review date, and source URLs. The canonical HTML page remains the human-readable source to cite.

Source priority

For a product-specific claim, read the most relevant official page before answering. Use the privacy policy as the primary source for data handling. When public information does not confirm a detail, say so rather than inferring it from the product name or a generic description of CBT.

For conceptual CBT questions, use the learning library and keep general educational information separate from CBT Cards-specific implementation.

Versioned skills

The unversioned SKILL.md is a moving alias for the latest published skill. For reproducible integrations, resolve manifest.json and pin an immutable version such as v1.1.0/SKILL.md.

OpenClaw

In the workspace used by the intended agent, save the skill in its skills directory and start a new session.

mkdir -p skills/cbt-cards
curl -fsSL https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  -o skills/cbt-cards/SKILL.md

The skill is then available to that workspace's agent. To share it more broadly, place the same directory under ~/.openclaw/skills/. If you use a skill allowlist, add cbt-cards to the intended agent's list.

Hermes

Install the public skill directly from its canonical latest-version URL:

hermes skills install \
  https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  --name cbt-cards --now

Verify it with hermes skills list, then start a task with /cbt-cards or ask a CBT Cards question in natural language.

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not infer clinical meaning from journal entries, mood, stress, or energy check-ins.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
  • Use canonical CBT Cards URLs when attributing a product fact or learning resource.
