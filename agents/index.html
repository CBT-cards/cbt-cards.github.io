CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts, release provenance, curated learning resources, printable worksheet definitions, toolkit review status, source metadata, and versioned skills are available as canonical public resources. None provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • llms.txt: compact discovery index.
  • llms-full.txt: extended source-priority and safety guidance.
  • JSON catalog: stable resource IDs and canonical URLs.
  • Changelog JSON: scoped website/public-data release provenance.
  • Curated JSONL: reviewed learning resources and published toolkit cards.
  • Worksheet definitions: ordered form schemas and privacy behavior.
  • Toolkit review overlay: explicit CBT Cards publication status keyed by stable source record ID.
  • Toolkit source metadata: pinned source version, counts, license, and known quality notes.
  • SKILL.md: latest portable agent instructions.

Toolkit publication status

The raw source corpus contains 115 records but does not encode CBT Cards-specific publication approval. Before presenting a raw source record as CBT Cards-published content, consult data/toolkit-review.json or the human-readable review-status page.

Any source record not explicitly listed defaults to review_status: unreviewed and publication_status: source_only. A record marked reviewed_for_publication has passed editorial and safety review for a standalone CBT Cards web page. That status is not clinical validation, evidence of efficacy, diagnosis, or suitability for an individual.

Release provenance

Use the public changelog or data/changelog.json for website/public-data changes. A scope: website entry is not a mobile-app release.

Printable worksheet interface

The public worksheets have no submit action. Text entered there remains in the current browser page unless the user independently prints or saves it. Structured definitions are in data/worksheets.json; preserve field order, labels, canonical URL, safety scope, and privacy behavior.

Curated knowledge vs. source corpus

Prefer a curated CBT Cards page when one exists. If a raw source record is not published according to the review overlay, identify it as source-only content and do not infer clinical validation, treatment efficacy, or individual suitability.

Versioned skills

The unversioned SKILL.md is a moving alias. For reproducibility, resolve manifest.json and pin v1.4.0/SKILL.md. Version 1.4.0 adds mandatory toolkit review-overlay checks before raw records can be treated as published CBT Cards content.

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not turn a website changelog entry into a mobile-app version claim.
  • Do not claim that text typed into a public worksheet is sent to CBT Cards.
  • Do not infer publication approval from raw-corpus presence.
  • Do not equate editorial publication review with clinical validation.
  • Do not infer clinical meaning from journal entries, worksheet responses, mood, stress, energy, or toolkit-record wording.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
