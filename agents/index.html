CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts, curated learning resources, printable worksheet definitions, toolkit records, and source metadata are available as canonical HTML, compact text indexes, JSON/JSONL data, and versioned agent skills. None of these resources provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • Web pages: best when an agent can browse and cite canonical pages directly.
  • llms.txt: compact discovery index for the main public resources.
  • llms-full.txt: extended source-priority, dataset, worksheet, versioning, and safety guidance.
  • JSON catalog: stable IDs, resource types, canonical URLs, product scope, worksheet pages, toolkit pages, and agent version metadata.
  • Curated JSONL knowledge dataset: self-contained records for reviewed learning resources and published toolkit cards.
  • Worksheet definitions: ordered field definitions, prompts, canonical pages, source links, safety scope, and privacy behavior for printable forms.
  • Toolkit source metadata: pinned source commit, blob SHA, record counts, license, distribution URL, and known quality notes for the related 115-record corpus.
  • SKILL.md: portable latest-version instructions for agents that support skill files.

Printable worksheet interface

CBT Cards publishes static browser worksheets for a CBT thought record, worry time, and activity planning. The pages have no submit action. Text entered into them remains in the current browser page unless the user independently prints or saves it.

An agent can use data/worksheets.json to render the same ordered prompts in another interface. Preserve the field order, labels, canonical URL, safety scope, and privacy behavior. Do not score the answers or present the prompts as a validated assessment.

Curated knowledge vs. source corpus

The curated knowledge.jsonl contains material that has a public CBT Cards learning or toolkit page and an explicit safety scope. The larger related CBT Toolkit source corpus contains 115 English records: 77 cards, 23 metaphors, and 15 protocols. It is useful for discovery and retrieval, but its records do not include per-record clinical-review metadata.

Prefer the curated CBT Cards page when one exists. If you use a raw source-corpus record, identify it as source content and do not infer clinical validation, diagnosis, treatment efficacy, or suitability for an individual.

See the human-readable toolkit landing page and machine-readable source manifest.

Source priority

For a product-specific claim, read the most relevant official page before answering. Use the privacy policy as the primary source for mobile-app data handling. When public information does not confirm a detail, say so rather than inferring it from the product name or a generic description of CBT.

For conceptual CBT questions, use the learning library. For a form, use the worksheet library. For product-owned card content, use a curated toolkit page when available.

Versioned skills

The unversioned SKILL.md is a moving alias for the latest published skill. For reproducible integrations, resolve manifest.json and pin an immutable version such as v1.3.0/SKILL.md. Version 1.3.0 adds explicit rules for public worksheet privacy and rendering.

OpenClaw

In the workspace used by the intended agent, save the skill in its skills directory and start a new session.

mkdir -p skills/cbt-cards
curl -fsSL https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  -o skills/cbt-cards/SKILL.md

Hermes

Install the public skill directly from its canonical latest-version URL:

hermes skills install \
  https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  --name cbt-cards --now

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not claim that text typed into a public worksheet is sent to CBT Cards.
  • Do not infer clinical meaning from journal entries, worksheet responses, mood, stress, energy, or toolkit-record wording.
  • Do not treat presence in the raw source corpus as evidence that a technique has been clinically reviewed by CBT Cards.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
  • Use canonical CBT Cards URLs when attributing a published product fact or curated resource.
