CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts, editorial freshness metadata, versioned data contracts, release provenance, curated learning resources, worksheet definitions, toolkit review status, source metadata, and agent skills are available as canonical public resources. None provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • llms.txt: compact discovery index.
  • llms-full.txt: extended source-priority and safety guidance.
  • JSON catalog: stable resource IDs, canonical URLs, and schema links.
  • Content review registry: review coverage, last-reviewed dates, and next-review deadlines for learning, worksheet, and curated toolkit-card resources.
  • JSON Schema manifest: versioned JSON Schema 2020-12 contracts.
  • Changelog JSON: scoped website/public-data release provenance.
  • Curated JSONL: reviewed learning resources and published toolkit cards.
  • Worksheet definitions: ordered form definitions and privacy behavior.
  • Toolkit review overlay: explicit CBT Cards publication status keyed by stable source record ID.
  • SKILL.md: latest portable agent instructions.

Editorial freshness

For a health-adjacent learning page, worksheet, or curated toolkit card, join the resource to data/content-review.json by catalog resource_id. The registry currently uses a 365-day internal review target. That cadence is a project maintenance policy, not a clinical standard.

If the current date is later than next_review_due, describe the editorial review as overdue instead of claiming a current review. Do not manufacture a later review date from sitemap lastmod, changelog activity, Git history, or a newer agent skill.

See the human-readable editorial review policy. “Reviewed” means source, wording, safety boundary, product relationship, and relevant privacy statements were checked for web publication. It is not clinical validation or efficacy evidence.

Versioned data contracts

Use schemas/index.json to discover the contract for a CBT Cards-owned JSON or JSONL resource. Purpose-specific CI checks still enforce semantic invariants beyond generic JSON Schema.

Toolkit publication status

Before presenting a raw source record as CBT Cards-published content, consult data/toolkit-review.json. Any unlisted source record defaults to unreviewed and source_only. reviewed_for_publication is editorial and safety review for web publication, not clinical validation or efficacy evidence.

Release provenance

Use the public changelog or data/changelog.json for website/public-data changes. A scope: website entry is not a mobile-app release.

Printable worksheet interface

The public worksheets have no submit action. Text entered there remains in the current browser page unless the user independently prints or saves it. Structured definitions are in data/worksheets.json.

Versioned skills

The unversioned SKILL.md is a moving alias. For reproducibility, resolve manifest.json and pin v1.5.0/SKILL.md. Version 1.5.0 adds editorial-freshness rules.

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not turn editorial review into a clinical-validation claim.
  • Do not infer review freshness from unrelated modification timestamps.
  • Do not turn a website changelog entry into a mobile-app version claim.
  • Do not claim that text typed into a public worksheet is sent to CBT Cards.
  • Do not infer publication approval from raw-corpus presence.
  • Do not infer clinical meaning from journal entries, worksheet responses, mood, stress, energy, or toolkit-record wording.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
