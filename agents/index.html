CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts, editorial freshness, website locale status, versioned data contracts, release provenance, curated resources, and toolkit publication status are available as canonical public interfaces. None provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • llms.txt: compact discovery index.
  • llms-full.txt: extended source-priority and safety guidance.
  • JSON catalog: stable resource IDs, canonical URLs, and schema links.
  • JSON Schema manifest: versioned JSON Schema 2020-12 contracts.
  • Content review registry: editorial review dates and next-review targets.
  • Website locale registry: published website locales and localization requirements.
  • Changelog JSON: scoped website/public-data release provenance.
  • Curated JSONL: reviewed learning resources and published toolkit cards.
  • Worksheet definitions: ordered form definitions and privacy behavior.
  • Toolkit review overlay: explicit publication status keyed by stable source record ID.
  • SKILL.md: latest portable instructions.

Website locale status

Use data/locales.json and the localization policy for the website only. The site currently publishes English (en) at the root URL.

Do not infer Android or iOS language support from the website locale registry. Mobile-app language claims require separately verified app/build or store metadata. A future second web locale requires reciprocal hreflang, stable locale URLs, synchronized discovery, and human review for health-adjacent translations.

Editorial review freshness

Use data/content-review.json when review freshness matters. The 365-day target is an editorial-maintenance rule, not a clinical standard. Do not manufacture a newer review date from sitemap lastmod, release activity, or a newer agent skill.

Toolkit publication status

Before presenting a raw source record as CBT Cards-published content, consult data/toolkit-review.json. Any unlisted record defaults to unreviewed and source_only. Editorial publication review is not clinical validation.

Versioned skills

The unversioned SKILL.md is a moving alias. For reproducibility, resolve manifest.json and pin v1.6.0/SKILL.md.

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not equate editorial review or publication review with clinical validation.
  • Do not infer mobile-app language support from website locale metadata.
  • Do not turn a website changelog entry into a mobile-app version claim.
  • Do not claim text typed into a public worksheet is sent to CBT Cards.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
