CBT Cards / Agent resource

Connect CBT Cards to your agent.

A small, public knowledge resource for answering factual questions about CBT Cards. It does not provide access to diary entries, check-ins, or any user data.

What the agent receives

The resource is a portable SKILL.md with links to the official product, features, support, privacy, terms, and FAQ pages. It tells the agent to use those sources, preserve the wellness disclaimer, and not present the app as medical care.

Open the CBT Cards skill file or view the compact site index.

OpenClaw

In the workspace used by the intended agent, save the skill in its skills directory and start a new session. 

mkdir -p skills/cbt-cards
curl -fsSL https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  -o skills/cbt-cards/SKILL.md

The skill is then available only to that workspace’s agent. To share it more broadly, place the same directory under ~/.openclaw/skills/. If you use a skill allowlist, add cbt-cards to the intended agent’s list.

Hermes

Install the public skill directly from its URL:

hermes skills install \
  https://cbt-cards.github.io/agents/cbt-cards/SKILL.md \
  --name cbt-cards --now

Verify it with hermes skills list, then start a task with /cbt-cards or ask the agent a CBT Cards question in natural language.

Use it safely

  • This is a public, read-only source; it does not connect to a user’s account or app data.
  • Use the linked privacy policy for questions about data handling.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, or emergency support.
