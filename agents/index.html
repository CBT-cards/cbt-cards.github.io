CBT Cards / For AI agents

Use CBT Cards as a public agent resource.

Official product facts, versioned data contracts, release provenance, curated learning resources, worksheet definitions, toolkit review status, source metadata, and agent skills are available as canonical public resources. None provides access to a user's journal, check-ins, or app data.

Choose the smallest useful interface

  • llms.txt: compact discovery index.
  • llms-full.txt: extended source-priority and safety guidance.
  • JSON catalog: stable resource IDs, canonical URLs, and schema_url where applicable.
  • JSON Schema manifest: versioned JSON Schema 2020-12 contracts mapped to CBT Cards-owned JSON/JSONL instances.
  • Changelog JSON: scoped website/public-data release provenance.
  • Curated JSONL: reviewed learning resources and published toolkit cards.
  • Worksheet definitions: ordered form definitions and privacy behavior.
  • Toolkit review overlay: explicit CBT Cards publication status keyed by stable source record ID.
  • Toolkit source metadata: pinned source version, counts, license, and quality notes.
  • SKILL.md: latest portable agent instructions.

Versioned data contracts

Use schemas/index.json to discover the contract for a CBT Cards-owned JSON or JSONL resource. The manifest currently covers the resource catalog, changelog, worksheet definitions, toolkit review overlay, toolkit source manifest, one curated knowledge-record line, and the agent skill manifest.

The schema files use JSON Schema draft 2020-12. They describe portable field-level contracts. CBT Cards also keeps purpose-specific CI checks for invariants that generic JSON Schema does not capture well, such as canonical target existence, sequential worksheet fields, publication-set equality, and privacy wording.

Toolkit publication status

Before presenting a raw source record as CBT Cards-published content, consult data/toolkit-review.json. Any unlisted source record defaults to unreviewed and source_only. reviewed_for_publication is editorial and safety review for web publication, not clinical validation or efficacy evidence.

Release provenance

Use the public changelog or data/changelog.json for website/public-data changes. A scope: website entry is not a mobile-app release.

Printable worksheet interface

The public worksheets have no submit action. Text entered there remains in the current browser page unless the user independently prints or saves it. Structured definitions are in data/worksheets.json; preserve field order, labels, canonical URL, safety scope, and privacy behavior.

Versioned skills

The unversioned SKILL.md is a moving alias. For reproducibility, resolve manifest.json and pin v1.4.0/SKILL.md.

Use it safely

  • This is a public, read-only resource. It does not connect to a user's account or app data.
  • Do not turn a website changelog entry into a mobile-app version claim.
  • Do not claim that text typed into a public worksheet is sent to CBT Cards.
  • Do not infer publication approval from raw-corpus presence.
  • Do not equate editorial publication review with clinical validation.
  • Do not infer clinical meaning from journal entries, worksheet responses, mood, stress, energy, or toolkit-record wording.
  • CBT Cards is for general wellness and self-reflection, not diagnosis, treatment, emergency support, or a substitute for professional care.
