# Contributing to CBT Cards

Submissions can propose practices, metaphors, evidence updates, safety-boundary corrections, translation review, or data/schema bugs. Submission is not publication or clinical validation.

Editorial states: `proposed -> evidence_review -> safety_review -> editorial_review -> published` or `proposed -> ... -> rejected`.

New practice proposals must include mechanism, plain-language situations, `best_used_when`, `avoid_when`, one bounded micro-action, follow-up, source/provenance, and whether wording is original, adapted, or quoted. A maintainer must explicitly move work to `published`. Machine drafts cannot self-certify as human reviewed. Source-only toolkit records remain governed by the toolkit publication overlay. Safety-critical changes require maintainer review. Breaking data changes require a new versioned contract.

Contributors must have the right to submit their wording. Do not paste copyrighted therapy manuals or paywalled text; link to sources and write project copy in original words.
