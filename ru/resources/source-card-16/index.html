Большие цели, маленькие шаги

Подсказка для планирования, которая помогает свести большую или расплывчатую цель к одному небольшому конкретному следующему действию с определёнными временем и местом начала.

Черновик перевода — нужна проверка
Это машинный черновик для языковой проверки, а не официальная публикация CBT Cards. Он исключён из поисковой индексации.

Основные пункты

  • Назовите более крупную цель.
  • Найдите самое маленькое заметное действие, которое продвигает вас вперёд.
  • Сделайте этот шаг конкретным.
  • Выберите, когда и где вы начнёте.
  • После первого шага решите, каким будет следующий.

Связь с CBT Cards

Опубликовано на основе записи card-16 из CBT Toolkit и связано с руководством CBT Cards по планированию активности.

Границы использования

Только для общего планирования и саморефлексии; не является индивидуальной рекомендацией по лечению.
