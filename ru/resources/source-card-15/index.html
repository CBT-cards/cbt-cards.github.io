Коробка беспокойств

Подсказка для рефлексии: записать беспокойство, временно отложить его и вернуться к нему намеренно, вместо того чтобы непрерывно прокручивать его в уме.

Черновик перевода — нужна проверка
Это машинный черновик для языковой проверки, а не официальная публикация CBT Cards. Он исключён из поисковой индексации.

Основные пункты

  • Чётко запишите беспокойство.
  • Выберите, когда вы к нему вернётесь.
  • До этого времени верните внимание к текущему делу.
  • При возвращении отделите практические следующие шаги от гипотетического беспокойства.

Связь с CBT Cards

Опубликовано на основе записи card-15 из CBT Toolkit и связано с руководством CBT Cards по технике выделенного времени для беспокойства.

Границы использования

Только для общей саморефлексии; при стойком или подавляющем беспокойстве может быть полезна поддержка квалифицированного специалиста.
