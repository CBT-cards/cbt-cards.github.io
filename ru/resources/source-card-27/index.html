Сократические вопросы

Короткий набор вопросов о фактах, альтернативных точках зрения и возможных следующих действиях, который помогает внимательнее рассмотреть свою интерпретацию ситуации.

Черновик перевода — нужна проверка
Это машинный черновик для языковой проверки, а не официальная публикация CBT Cards. Он исключён из поисковой индексации.

Основные пункты

  • Спросите, какие факты поддерживают эту мысль.
  • Спросите, какие факты с ней не согласуются.
  • Рассмотрите другой способ понять ситуацию.
  • Выберите действие, опираясь на наиболее сбалансированное из доступных объяснений.

Связь с CBT Cards

Опубликовано на основе записи card-27 из CBT Toolkit и связано с ресурсами CBT Cards о дневнике мыслей и различении мысли и факта.

Границы использования

Только для образовательной саморефлексии; не является индивидуальной терапией и не предназначено для обесценивания переживаний человека.
