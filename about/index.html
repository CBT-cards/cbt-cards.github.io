CBT Cards / About

Useful ideas should outlive the app that carried them.

CBT Cards started as a mobile reflection app. The project now publishes a smaller, inspectable public layer that people can use directly and AI assistants can consume without guessing what is reviewed, current, or safe to reuse.

From product to public resource

The original mobile app combined visual cards, guided tools, journaling, and personal check-ins. The public project keeps useful reflection material available beyond one app install while keeping public resources separate from private app data.

A public resource needs stable IDs, canonical URLs, evidence notes, safety boundaries, language status, review dates, machine-readable contracts, and tests that catch the project when its own claims drift.

What CBT Cards publishes now

  • Eleven CBT Cards-owned reviewed practices organized around plain-language situations, explicit mechanisms, small actions, exclusions, and no_match.
  • Learning guides and browser-local worksheets with narrow educational scope.
  • A pinned 115-record source toolkit with separate publication status and a record-complete editorial audit.
  • Editorial freshness, evidence/provenance, semantic recommendation evals, stable RAG chunks, language metadata, schemas, and a versioned Agent Skills interface.

Trust boundaries

Publication status says which raw source records CBT Cards has explicitly approved for a standalone canonical page. Unlisted source records stay source-only.

Source-corpus audit triages all 115 source records for overlap, framework attribution, overclaim, treatment-like wording, and future review priority. Candidate status is not publication approval.

Editorial freshness records when already trusted resources were last checked and when review is due again. A newer Git commit is not automatically a newer content review.

Editorial review is not clinical validation. Evidence for a mechanism is not automatically evidence for the exact wording of a short card. Metaphors help memory; they do not prove claims.

Languages

English is the canonical source locale for current curated knowledge. Russian currently has machine-draft overlays and German is planned. Website translation state is separate from mobile/store language support; see Languages and the repository's mobile-locale audit.

Original mobile app

The app remains separately documented through features, how it works, privacy, support, and the store-sourced mobile release history. Public-site releases, dataset changes, or agent-skill versions do not imply a new Android or iOS release.

Project state

The repository keeps a concise verified maintainer snapshot in PROJECT_STATUS.md. Machine-readable source data remains authoritative over summary prose.

Publisher

CBT Cards is published by MetalHatsCats. Public project data is read-only and does not expose a user's journal, check-ins, backups, or account.
