Challenge Your Thoughts

A short prompt for slowing down one difficult thought instead of treating the first interpretation as the only possible account.

Try the card

  1. Choose one specific situation that felt difficult.
  2. Write the thought that showed up in that moment.
  3. Ask what information supports that interpretation and what information does not.
  4. Write a more balanced or useful alternative if one genuinely fits the situation.

This is not about forcing a positive thought. The useful question is whether there is a fuller, more realistic way to describe what happened.
