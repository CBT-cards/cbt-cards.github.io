Worry Box

A prompt for recording a worry so you do not have to keep rehearsing it every time it returns.

Try the card

  1. Write the worry in one clear sentence.
  2. Choose a deliberate time when you can return to it.
  3. Until then, remind yourself that the worry has been recorded.
  4. At the chosen time, decide whether there is a practical next step or whether the worry is mainly hypothetical.

The point is not to promise that the worry is unimportant. It is to separate “I noticed this concern” from “I must keep thinking about it continuously.”

Source and scope

Source record: card-15 in the public MetalHatsCats CBT Toolkit v0.1.0. The source prompt asks the user to write worries down, set them aside, and decide when or whether to deal with them.

This card is for general self-reflection. Persistent or overwhelming worry may warrant support from an appropriate qualified professional.
