CBT Cards public changelog

Website and public-data changes, recorded separately from mobile-app releases.

Machine-readable history is available in data/changelog.json. A website, data, or agent entry does not imply that an Android or iOS app version shipped on the same date.

18 August 2026 · Website

Website locale source of truth and localization guardrails

Added a website localization policy, machine-readable locale registry, versioned locale schema, CI checks, and agent skill v1.6.0. The site currently publishes English at the root URL. Website locale metadata is explicitly not a source for Android or iOS language support.

18 August 2026 · Website

Editorial review freshness registry

Added the editorial review policy and review registry for learning, worksheet, and curated toolkit-card resources. The 365-day review target is a maintenance rule, not clinical validation.

18 August 2026 · Website

Indexed-page crawl graph quality gate

Added direct homepage links to major public-resource hubs and a CI rule rejecting orphaned or excessively deep sitemap pages.

18 August 2026 · Public data

Versioned public JSON Schema contracts

Published JSON Schema 2020-12 contracts and a schema manifest for CBT Cards-owned structured resources.

18 August 2026 · Website/public data

Toolkit review and publication overlay

Added review status and machine-readable publication status. Unlisted source records default to unreviewed and source-only; publication review is not clinical validation.

18 August 2026 · Website/public data

Knowledge, worksheets, agent data, and discovery foundation

Expanded the standalone site with sourced learning guides, printable browser-local worksheets, curated toolkit pages, structured agent data, feeds, and quality checks.

14 July 2026 · Website

Standalone CBT Cards website

Established the standalone public site at cbt-cards.github.io with canonical product, privacy, terms, support, FAQ, and feature documentation.
