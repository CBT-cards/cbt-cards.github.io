Public by design

Readable by people. Predictable for software.

The same project publishes human-readable pages and machine-readable resources with stable IDs, canonical URLs, review status, versioned schemas, and release provenance.

That means an assistant does not need to scrape a marketing page and improvise. It can use the public resource catalog, curated JSONL dataset, schemas, and agent skill.

Review and provenance
